# 01. 양식 구조 ↔ 평가지표 매핑 + 섹션별 작성전략

> 양식: 「협업과제 수행계획서」 (업스테이지 과제1 — Solar LLM 기반 소크라틱 학습 AI 튜터 Agent)
> 원칙: 각 섹션을 **평가위원이 채점하는 항목**에 맞춰 작성. 모든 주장에 **숫자·근거·도식**.

| 2 | 협업과제 신청현황 | 업스테이지 ❶에 **■** 체크 (세부과제 ①②③ 모두 이행) | (요건) |

## 섹션별 작성 전략 (업스테이지 소크라틱 튜터 맞춤)

### 3-1) 협업과제 소개 — [①과제 이해도]
- **제안배경**: 기존 AI 튜터의 한계 = "정답을 바로 알려줌 → 학습자 사고력 저하". 소크라틱 = 스스로 답을 찾게 유도. 시장/교육적 니즈를 숫자로(예: 사교육비, 자기주도학습 결손, 기존 챗봇 답 베끼기 문제).
- **제품 개요**: 우리 서비스가 무엇이고, 소크라틱 튜터가 어디에 붙는지.
- **주요 기능/성능**: 세부과제 ①②③를 우리 제품의 기능으로 1:1 매핑해 설명.
  - ① 학습자 의도·**오개념 진단** → 무엇을 입력받아 어떤 오개념을 어떻게 분류/탐지?
  - ② **소크라틱 발문 생성 엔진** → 정답 노출 없이 단계적 질문을 생성하는 방식
  - ③ **개인화 학습 이력 RAG** → 학습 이력을 저장·검색해 다음 발문에 반영
- KPI 예시: 오개념 진단 정확도 ≥ X%, 발문 적절성(전문가 평가) ≥ X점, 정답 직접노출률 ≤ X%.

### 3-2) 기술 경쟁력 — [③기술경쟁력 / ⑤LLM 활용성]
- 우리만의 보유기술(데이터셋, 알고리즘, 기존 서비스 트래픽/모델 등) = "왜 우리가 이걸 제일 잘 만드나".
- **Solar LLM·Document Parse·Information Extract 활용 지점**을 명시(평가지표 '수요기업 LLM 활용성'에 직결).
- 경쟁기술 대비 차별성: 일반 GPT 챗봇/타 에듀테크 대비 표로 비교. 완성수준(현재 TRL/PoC/MVP 상태).

### 4-1) 협업 목표 및 추진전략 — [①이해도 / ②접합성]
- 정량 목표(6개월 종료 시점 달성치)를 SMART하게.
- **추진전략 = 업스테이지와 어떻게 협업하나**: Solar Open·Console API 크레딧·온프레미스 라이선스·NFM센터/Edu팀 멘토링을 단계별로 활용.

### 4-2) 팀 구성 — [③개발역량]
- 일반현황 인력표와 일관되게. 각 팀원: 담당업무 + 보유역량(경력·학력) + 본 과제 참여율(%).
- "이 팀이 6개월 안에 ①②③를 만들 수 있다"가 보이게(LLM/NLP/교육 도메인 경험 강조).

### 4-3) 수행계획 — [④PoC 실현가능성 / ⑥실행전략 / ②접합성] ★가장 중요
- **월 단위 마일스톤(M1~M6)**: 데이터 구축 → ① 진단모델 → ② 발문엔진 → ③ RAG → 통합 → 현장검증.
- **수요기관 협업방안**: 업스테이지 제공자원(데이터/모델/멘토링)을 각 단계에 매핑.
- **PoC 수행계획**: 어디서·누구를 대상으로·몇 명·어떤 지표로 검증? (예: 학습자 N명, 발문 품질·오개념 진단 정확도·학습효과 사전사후 비교).

### 5-1) 사업성 — [⑦효과성 / ⑧사업화]
- 목표시장: TAM/SAM/SOM(에듀테크/영어교육/AI튜터 시장 규모, 출처 명시).
- **수요기관(업스테이지)에 미치는 영향**: Solar 교육 도메인 레퍼런스 확보, API 사용량 견인 등 — "업스테이지가 우리와 협업할 이유".
- 사업화 경로: PoC→상용화(B2C 앱 / B2B 학교·학원), 매출 추정, 가격모델.

### 5-2) 확장·지속 가능성 — [⑧확장]
- 과목 확장(영어→수학/과학), 해외(글로벌 영어학습), 후속 투자·매출 로드맵.
- 가점: 선정 시 '27 초격차 스타트업 프로젝트 서류 가점 2점 → 후속 스케일업 연계.

### 6) GPU 활용계획 — (필요 체크 시만)
- 필수성: 소크라틱 발문엔진/진단모델 **파인튜닝·온프레미스 서빙**에 GPU 필수 논리.
- 타당성/기대효과: B200 활용 시 학습속도·지연시간·보안(온프레미스) 개선치.
- ※ '불필요' 선택 시 6번 전체 생략 가능 → 대표님 결정 필요.

### 7) 사업비 집행계획 — PoC 현금 1억원 기준
- 항목/산출근거/금액. **핵심기술 개발 외주 용역비는 집행 불가**(공고 명시) → 외주는 비핵심(검증·디자인 등)만.
- 예시 배분(조정 필요): SW·API/크레딧, 클라우드·서버, 데이터 구축·라벨링, 기자재, 인건비, 시험·검증비.
