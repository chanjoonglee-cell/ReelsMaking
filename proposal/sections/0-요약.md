# 창업아이템 개요 (요약)

## 작성 메타
- **양식 itemId**: OV (요약 표)
- **양식 구조**: 표 형식 — 각 칸에 텍스트 채우기 + 이미지 2장
- **분량 가이드**: 1p (표 1장 + 이미지 2장)

---

## 표 내용 (한글 양식 표 칸에 그대로 입력)

| 칸 | 입력 내용 |
|---|---|
| **창업 아이템명** | AI Agent가 사용자의 일상을 학습 콘텐츠로 변환하는 개인화 언어학습 앱 「영어의숲」 |
| **창업아이템 소개** | 일기·SNS·검색 기록 등 유저의 일상 데이터를 입력받아, 관심사·언어 수준·감정 상태에 1:1 매칭된 영어 학습 콘텐츠를 실시간 생성하는 AI Agent 기반 모바일 앱. iOS·Android 정식 출시 완료, 누적 다운로드 8,200명·MAU 2,400명, D1 리텐션 30%로 동종 업계 평균 대비 1.5~2배 검증 완료. |
| **배경 및 필요성** | 글로벌 언어학습 시장은 60조 원 규모로 고성장 중이나 모바일 앱의 D30 리텐션은 평균 2%에 그치는 구조적 실패 [⚠ 출처보강필요]. 공급자 중심의 정형 콘텐츠(객관식·쉐도잉)가 학습자의 관심사·수준·심리적 부담을 반영하지 못하기 때문. 영어의숲은 "내 일상을 외국어로 표현"이라는 언어학습의 본질을 AI 초개인화로 구현해 리텐션·효능감을 동시에 끌어올림. |
| **목표시장 및 사업화 전략** | 1차 타깃: 국내 2535 여성 자기계발 시장 (1조 원). 확장: 2027년 일본·북미(한국어 학습 수요 + 객단가 높음) → 2028년 동남아·중남미. BM: ①구독+광고 → ②F2L 마이크로결제(1,500원) → ③프리미엄 팩 → ④B2B/B2G 학습 엔진 납품. 2026년 매출 5억·ROAS 300% 목표, 시드+TIPS 9억 유치 계획. |
| **현황 및 구체화 방안** | 출시 1개월 만에 유료 매출 900만 원·ROAS 214% 달성. 협약기간 내 3가지 핵심 기술 고도화: ①RAG 모델(유저 장기 기억), ②데이터 입력 자동화(LLM 기반 자동 일기), ③자동복습 시스템(에빙하우스 곡선 기반). 대전창조경제혁신센터 시드 투자 확약, 2026 Q3 TIPS 유치 목표. 자문위원: OO과학기술원 미래전략대학원 부교수(과기정통부 R&D 전략위원). |

---

## 이미지 가이드 (사용자 작업)
- **이미지 1**: 영어의숲 앱 메인 화면 (개인화 학습 콘텐츠 예시) — 양식의 첫 이미지 칸
- **이미지 2**: 영어의숲 핵심 메커니즘 도식 (일상 데이터 → AI Agent → 개인화 콘텐츠 → 리텐션 상승) — 양식의 두 번째 이미지 칸

## ⚠ 출처 보강 필요
- [ ] 글로벌 언어학습 시장 60조 원
- [ ] 모바일 앱 D30 리텐션 2%
- [ ] 국내 영어학습 시장 1조 원
- [ ] "동종업계 평균 대비 1.5~2배" 비교 기준

## 자가체크
- 표 각 칸 1~3문장 내 (양식 공간 고려)
- 핵심 수치 5개 노출: 8,200 / 2,400 / D1 30% / 매출 900만 / ROAS 214%
- 평가위원 첫인상 결정 페이지 — 임팩트 우선
