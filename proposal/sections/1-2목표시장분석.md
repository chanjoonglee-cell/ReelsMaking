   - 페르소나 특징: 영어 실패 경험으로 적극적 학습은 부담, 그러나 영어 "감"을 유지하려는 욕구 강함 — 모바일 학습 앱이 "심리적 안정제" 역할 수행
   - 미충족 니즈: 본인 일상·관심사 기반 학습 콘텐츠. 기존 앱의 객관식·쉐도잉은 "내 이야기를 영어로"라는 본질을 못 채움

 ◦ (시장 특성·경쟁) 단일 앱 독점이 아닌 병행 사용 시장 — 데이터 락인이 진입장벽
   - 유저의 50% 이상이 복수 언어학습 앱을 병행 사용 — 직접 경쟁이 아닌 보완적 포지셔닝 가능 (자체 측정)
   - 데이터 누적이 곧 진입장벽: 사용할수록 관심사·수준·성향 데이터가 쌓여 콘텐츠 정밀도 자가 향상 → 후발 주자가 모방 불가
   - 효능감 기반 SNS 바이럴 특성: 메인 타깃은 학습 성과·일상 학습 모먼트를 자발적으로 SNS 공유 — CAC 절감 + 자연 유입 채널

 ◦ (파급효과) "내 이야기를 외국어로 표현"이라는 본질 재정의로 시장 전반의 학습 효능감 회복
   - 글로벌 D30 2% 문제를 D30 10%+로 끌어올린 첫 사례 확보 시, 학습 메커니즘 엔진을 B2B로 공급하는 후속 시장(3-1 BM Phase3) 개창 가능
