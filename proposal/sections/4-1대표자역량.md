# 4-1. 대표자 현황 및 역량

## 작성 메타
- **양식 itemId**: 4-1
- **평가지표**: 팀구성(T) 10점 中 약 5점
- **분량 가이드**: 본문 약 0.5p (~400자)
- **양식 안내 요구**: 제품·서비스 관련 보유 이력·역량, 공동대표 시 전원 기재
- **구조**: ◦ 학력·정부공인 / ◦ 사업 직결 실무 이력 / ◦ 핵심 인사이트·비전

---

## 본문 (한글 복붙용)

```
 ◦ (학력·정부공인) 인지심리학·학습과학·데이터사이언스 융합 연구 + 정부 공인 이공계 인재
   - OO과학기술원 미래전략대학원 석사 (2025~) — 인지심리학·학습과학·데이터사이언스를 기반으로 한 데이터 기반 학습 전략 연구
   - 00대학교 예술공학과·스타트업 전공 (2018~2024) — 대통령과학장학생(국가이공계인재), 대한민국 인재상 수상
   - 학술·정부 모두 공인된 이공계 인재로, 본 사업 아이템(AI 기반 개인화 학습)의 학문적 기반 확보

 ◦ (실무 이력) 상장 게임사·에듀테크에서 사용자 몰입·KPI 개선 메커니즘 직접 설계
   - 상장 게임사(2022·2024) IP전략팀·신사업개발팀 — 인기 게임 IP 확장 전략 수립 + 신작 KPI 설계로 체류시간 3.5배 달성
   - 00게임즈(2022~2023) 전략TF팀 — 자사·경쟁사 게임 리서치, 게임 내 경제 활성화 전략 수립
   - 시리즈 B 에듀테크(2021) 비즈니스 콘텐츠 전략팀 — AI 교육 콘텐츠 공급 파이프라인 구축, 마케팅 콘텐츠 제작으로 유입률 3배 증가
   - "사용자를 머무르게 하는 메커니즘"을 게임·교육 양 도메인에서 실제 사업으로 입증

 ◦ (핵심 인사이트·비전) 언어학습 = 게임 메커니즘 → AI로 1:1 개인화
   - 연구·실무를 오가며 발견: 언어학습과 게임은 "내적 동기 + 즉시 보상 + 점진적 숙련" 동일 원리 위에 있음
   - AI는 이 원리를 1:1 개인화할 수 있는 첫 번째 기술 — 본 사업의 학문적·실무적 정합성 확보
   - 비전: 영어의숲을 시작으로 글로벌 언어교환 소셜 학습 플랫폼으로 확장, 학습 효능감 문제 해결
```
