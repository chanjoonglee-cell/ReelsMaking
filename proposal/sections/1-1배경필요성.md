# 1-1. 창업아이템의 개발 배경 및 필요성

## 작성 메타
- **양식 itemId**: 1-1
- **평가지표**: 문제인식(P) 20점 中 10점
- **분량 가이드**: 본문 약 1p (이미지 1장 포함 가정 → 본문 텍스트 ~500자)
- **구조**: ◦ 외적 동기 + [이미지] / ◦ 내적 동기 / ◦ 혁신적 해결방안+고객혜택
- **양식 안내 요구**: ①외적 동기, ②내적 동기, ③혁신적 해결방안 + 고객 혜택
  - (※ "현재 개발 상태"는 2-1로 이동 — 2-1 가이드와 중복)

```
 ◦ (외적 동기) 60조 원 글로벌 언어학습 시장의 구조적 이탈률 문제
   - 글로벌 모바일 언어학습 시장은 2025년 약 60조 원 규모로 연평균 17% 이상 고성장 [⚠ 출처보강필요: Statista 또는 Mordor Intelligence 보고서명]
   - 그러나 동일 시장의 D30 리텐션은 평균 약 2%에 그쳐, 시장은 커지는데 학습자는 머물지 못하는 구조적 실패가 지속 [⚠ 출처보강필요]
   - 원인: 공급자 중심의 정형 콘텐츠(객관식·쉐도잉)가 학습자의 관심사·수준·심리적 부담을 반영하지 못함

< 글로벌 언어학습 시장 규모 vs 모바일 앱 D30 리텐션 비교 >

 ◦ (내적 동기) 인지심리학·학습과학·게임 메커니즘을 융합 설계한 검증된 역량
   - 대표자: OO과학기술원 미래전략대학원에서 인지심리학·학습과학·데이터사이언스를 융합한 학습 전략 연구. 대통령과학장학생·대한민국 인재상 수상자로 정부 공인 이공계 인재
   - 실무 이력: 상장 게임사(IP전략·신사업·전략TF)와 시리즈B 에듀테크에서 KPI 설계로 체류시간 3.5배 개선, 콘텐츠 유입률 3배 증가 등 "사용자를 머무르게 하는 메커니즘"을 사업으로 입증
   - 핵심 인사이트: 언어학습과 게임은 "내적 동기 + 즉시 보상 + 점진적 숙련"이라는 동일 원리 위에 있음. AI는 이 원리를 1:1로 개인화할 수 있는 첫 번째 기술

 ◦ (혁신적 해결방안) 유저의 일상 데이터를 학습 콘텐츠로 변환하는 AI Agent
   - 일기·SNS·검색 기록 등 유저의 실제 일상을 입력으로, 관심사·언어 수준·감정에 1:1 매칭된 학습 콘텐츠를 실시간 생성(인출 기반 학습 + 초개인화 소재)
   - 고객 혜택: ①흥미 있는 소재로 심리적 부담 해소, ②본인 수준 맞춤 난이도로 학습 효능감 확보, ③"내 이야기를 외국어로 표현"이라는 본질 직결, ④사용할수록 데이터 축적되어 콘텐츠 정밀도 자가 향상
   - 시장 내 일상 데이터 기반 학습 콘텐츠 생성을 모바일 앱으로 구현한 사례는 현재 시장 조사 범위 내에서 영어의숲이 유일하게 확인됨
```

## 분량 자가체크
- 본문 텍스트: 약 480자 (한글 양식 1p 안전 마진)
- 이미지 1장 포함 시 정확히 1p 차지
- 안내문(파란 ※) 삭제 후 본문 시작 — 한글에서 처리

## 이미지 가이드 (사용자 작업)
- 위치: ◦ 외적 동기 블록 직후
- 캡션: `< 글로벌 언어학습 시장 규모 vs 모바일 앱 D30 리텐션 비교 >`
- 추천 형태: 좌측 시장 규모 막대그래프(60조원·CAGR 17%), 우측 D30 리텐션 2%만 표시한 비교 차트
- 출처 표기: 차트 하단 작은 글씨로 "출처: …" 명기

## ⚠ 출처 보강 필요
- [ ] 글로벌 언어학습 시장 60조원·CAGR 17% — Statista/Grand View/Mordor 중 어느 보고서?
- [ ] 모바일 언어학습 앱 평균 D30 리텐션 2% — 어디 데이터?
- [ ] (참고) 본인 D1 리텐션 30%·MAU 2,400·매출 900만원은 자체 측정값 → 2-1에 배치

- 이미지 자리 명시적 표기
- 출처 미확인 데이터에 `[⚠ 출처보강필요]` 마커 통일
