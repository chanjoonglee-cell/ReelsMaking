## 본문 (한글 복붙용)

```
 ◦ (5단계 풀퍼널 BM) 구독·광고 → 마이크로결제 → 프리미엄 → B2B/B2G의 단계적 LTV 극대화
   - Core (출시 직후~): AdMob 기반 광고 수익 + 기본 구독 — 무과금 유저층 트래픽 가치 확보, 신규 유입 극대화
   - Phase 1 (현재): F2L(Free to Learn) + 마이크로결제 1,500원 — AI Agent의 특정 고가치 기능을 소액 결제 단위로 분리
   - Phase 2 (2026 Q4~): 프리미엄 팩 — 시험 대비·비즈니스 영어 등 고도화 시나리오 패키지 (객단가 ↑)
   - Phase 3 (2027~): B2B/B2G — 검증된 학습 메커니즘 엔진(개인화·RAG·자동복습)을 기업 LMS·공교육에 라이선스 납품
   - 광고 → 학습자 → 결제자 → 충성 결제자 → 데이터 라이선싱으로 LTV 5단 점프업

< 5단계 풀퍼널 BM 및 단계별 수익원 >
| 단계 | 수익원 | 객단가 | 핵심 KPI |
| --- | --- | --- | --- |
| Core | 광고·기본 구독 | 저 | DAU, 광고 노출 |
| Phase 1 | 마이크로결제(₩1,500) | 저~중 | 결제 전환율, ARPPU |
| Phase 2 | 프리미엄 팩 | 중~고 | 패키지 구매율 |
| Phase 3 | B2B/B2G 라이선스 | 고 | 계약 ARR |

 ◦ (단위 경제성·LTV) 광고로 진입 → 데이터 축적 → 결제 전환의 자가 강화 루프
   - 진입 마찰 0: 광고 기반 무료 시작으로 CAC 부담 분산
   - 데이터 락인: 사용할수록 관심사·수준·성향 데이터가 누적 — 콘텐츠 정밀도 자가 향상 = 이탈 비용↑
   - 결제 트리거: 핵심 가치(AI Agent 개인화 응답·자동 일기)는 마이크로결제 단위로 분리 — 가격 부담 최소, 결제 빈도 최대화

 ◦ (라이브 검증) 출시 1개월 만에 BM 작동 1차 검증
   - 유료기능 출시 1개월 매출 900만 원, ROAS 214% (마케팅비 약 420만 원 대비)
   - 누적 매출 1,300만 원, 공헌이익 흑자 (현재는 제품 고도화 위해 마케팅 의도적 OFF 상태)
   - "광고 ON 시 ROAS 200%+ 유지 가능" 가설 → 본 사업 협약기간 종료 후 본격 마케팅 집행으로 검증 예정
```

- 3개 ◦ 블록 (BM 구조 → 단위 경제성 → 라이브 검증)
- 평가위원이 가장 좋아하는 "이미 매출 발생" 카드를 마지막에 배치
