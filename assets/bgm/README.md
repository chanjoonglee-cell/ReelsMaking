# BGM 파일 준비 | BGM File Setup

이 폴더에 아래 4개의 MP3 파일을 직접 넣어주세요.  
Place the following 4 MP3 files in this directory manually.

| 파일명 | 무드 | 추천 느낌 |
|--------|------|-----------|
| `warm.mp3` | warm | 따뜻하고 행복한 어쿠스틱 / Warm happy acoustic |
| `calm.mp3` | calm | 잔잔하고 평화로운 피아노 / Peaceful piano |
| `energetic.mp3` | energetic | 밝고 신나는 팝 / Upbeat pop |
| `melancholic.mp3` | melancholic | 감성적이고 서정적 / Emotional cinematic |

## 저작권 없는 BGM 소스 | Royalty-Free BGM Sources

- **Pixabay Music** — https://pixabay.com/music/ (무료, 상업적 이용 가능)
- **Free Music Archive** — https://freemusicarchive.org/
- **Incompetech** — https://incompetech.com/ (CC 라이선스)
- **YouTube Audio Library** — YouTube Studio에서 다운로드 가능

> **주의**: BGM 파일 없이도 영상 생성은 가능합니다 (무음으로 진행됩니다).  
> **Note**: The generator will still work without BGM files — it will produce a silent video.
