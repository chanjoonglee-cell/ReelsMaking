## ① 사업내용 핵심  *(기술분야·용도·성능·특징·강점 / 12줄 이내)*

**[기술분야]** 인지심리학·학습과학·데이터과학(AI)을 융합한 **개인화 언어학습 시스템**. 유저의 일상(사진·일기)을 학습 데이터로 변환해, 학습자가 스스로 영어 문장을 *인출(retrieval)* 하도록 설계한 학습 엔진 기반 모바일 앱 **‘영어의숲’**(iOS·Android, ’25.12 출시).

**[해결 문제]** 60조 원 규모의 글로벌 언어학습 시장은 성장하지만 30일 리텐션은 2%에 불과하다. 원인은 학습자의 의지가 아니라 *기억에 남지 않는 학습설계*다. 객관식·쉐도잉·반복학습은 장기기억으로 이어지지 않는다.

**[용도·작동]** ① 유저가 일상 사진·일기를 입력하면 → ② AI가 유저 수준에 맞는 난이도로 학습 소재를 자동 생성하고 → ③ 정답을 보여주는 대신 학습자가 직접 영어 문장을 *인출*하게 하며 → ④ 즉각 교정 피드백과 함께 학습 기록을 정서 데이터로 시각화해 효능감을 높인다.

**[핵심 기술·특징]** (1) **인출 기반 학습**(retrieval practice): 입력이 아닌 산출 중심 설계로 장기기억 강화 (2) **개인 데이터 기반 소재 추천**: 유저의 일상이 곧 콘텐츠 (3) **난이도 자동 조정**: 수준 불일치로 인한 이탈 방지 (4) **정서 데이터 시각화**: 멘탈케어형 리텐션 루프. → 4축 결합 학습 메커니즘 **특허 출원 완료(10-2025-0146995)**.

**[성능·검증]** 광고 없이 **D1 리텐션 30.1%(동종업계 약 2배)**, 리텐션 플래토 30% 유지. **유료 출시 1개월 만에 매출 900만 원 돌파(공헌이익 흑자)**, 앱스토어 교육 카테고리 **TOP 12**. → PMF 검증 완료, 스케일업 단계.

**[강점]** 경쟁사(듀오링고 등) 대비 *적은 학습시간·인출 기반·개인화 소재*로 대체 불가한 락인. 쓸수록 개인 데이터가 쌓여 추천·난이도·정서 시각화가 정교해지는 **데이터 해자**. 해외(영미권) 결제 전환이 국내 대비 **2.7배**로 글로벌 확장성까지 검증.
