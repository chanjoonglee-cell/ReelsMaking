# 언어의숲 유저 세그먼트 분석

활성화(Activation), 재방문(Retention), 결제(Revenue) 관점에서 "누가 우리 앱을 쓰는가"를 다시 정의한다. 컨설턴트 피드백 — **"데모가 아니라 니즈로 세그먼트하라"** — 을 핵심 축으로 삼고, 한국 유저 인터뷰 10건의 정성 + 2026.5 마케팅·결제 정량 데이터를 교차해 본다.

근거 인용은 `docs/interview-coding.md`의 가명/번호로 추적할 수 있다.

---

## TL;DR

- **활성화는 25–35 한국 여성에 몰린다.** 일상 표현의 답답함(자기효능감 클러스터) + 가까운 커리어 이벤트(외국계 입사·박사 지원·외항사 면접)가 두 축. 사용 빈도는 후자가 압도적으로 높다.
- **재방문은 "감정·라포 + 트리거"에 좌우된다.** 캐릭터(수프) + AI 코멘트가 핵심 매력. 데이터 기반 cohort에서 *진짜* 데일리 유저는 명확한 외적 데드라인(노바/이가원/이선영)이나 라포 의존(김윤태)을 가진 사람이고, 나머지는 일기 소재 부재로 드문드문 사용한다.
- **결제는 두 갈래로 나뉜다.** (1) 한국 1개월 ₩15,900 — 의향은 있지만 가격·UX 마찰로 미진. (2) 해외(US/CA/AU) 12개월 ₩87k~108k — 정성 데이터 부재 (인터뷰 미보유).
- **Korea–Overseas 갭이 핵심 텐션.** 최근 마케팅에서 인스톨 84%·신규결제 다수가 해외다(가설). 인터뷰는 한국인 only → 한국 페르소나만 검증됨. 해외는 hypothesis.
- **#1 마케팅 액션:** 한국 "옵션 비즈니스" 특성상 데드라인(B 세그먼트) 또는 라포(E 세그먼트) 페르소나에 페이드를 집중. 자기효능감(A) 세그먼트는 모수는 크지만 LTV 약함, 페이드 ROAS 위험.

3. 초대코드/이벤트 진입점 부재 (#02 손서연 — 결제 직전 좌절)
4. iPad/Mac 미지원 (#07 이가원 — 즉시 결제 가능 케이스)

## 니즈 기반 페르소나 (한국 데이터 기반·검증됨)

5개 클러스터를 4개 페르소나로 합성. 각 페르소나는 인터뷰 ≥2건의 근거가 있다.

### 페르소나 1 — "데드라인 가원" (커리어 진입형)
**근거**: #09 노바, #07 이가원, #05 이선영

| 차원 | 내용 |
|------|------|
| 핵심 니즈 | 가까운 외적 이벤트(면접·시험·입사·박사 지원)에 영어 사용 직면 |
| 데모 correlate | 24–26세 여성, 학생/사회초년생, 토익 800+ 또는 토플 90+ |
| 트리거 | 명확한 데드라인 (외항사 면접·박사 지원·외국계 첫 출근) |
| 활성화 hook | "내 이야기로 영어" → 면접·스몰톡 표현 즉시 활용 가능 |
| Retention 패턴 | **매일 또는 주 5회**. 데드라인이 가까울수록 burst. 다른 학습 도구(전화영어·스픽)와 병행. |
| 결제 의향 | **가장 강함**. 막는 건 가격 아닌 기능 부재 (iPad #07 / 복습 #05). |
| 대표 quote | "내 이야기를 하는 게 가장 크게 중요해요. 면접도 결국 내 이야기니까." (#07) |

**마케팅 함의**: 외항사·외국계·유학생 커뮤니티 타겟. "면접/시험 대비" 페이드 카피. iPad·Mac 지원이 LTV 직접 영향.

### 페르소나 2 — "답답한 효진" (자기효능감 / 일상 표현형)
**근거**: #11 Katie Kim, #10 조연숙, #02 손서연, #06 김효진(부분), #04 염고운(부분)

| 차원 | 내용 |
|------|------|
| 핵심 니즈 | "한국어로는 표현 가능한데 영어로는 어색"이라는 일상의 격차. "평생 영어 잘하고 싶었다"는 longstanding 콤플렉스. |
| 데모 correlate | 26–36세 여성, 직장 보유 또는 이직 준비, 영어 평생교육 관점 |
| 트리거 | 외부 사건 없이 누적된 답답함. 연초·연말 자기개발 시즌과 결합. |
| 활성화 hook | "메뉴판 한 문장이라도 직접 영어로", "내 일상 작은 표현을 자연스럽게" |
| Retention 패턴 | **드문드문**. "쓸 만한 일이 없다"는 일기 소재 부재가 가장 큰 이탈 원인. 캐릭터·다이어리 누적의 시각적 보상이 재방문 유도. |
| 결제 의향 | **중간**. 의향은 있으나 가격 인식 충돌(\#04 — 6,900원도 비싸다 / #08 — 부담 없다). 무료/유료 차이 인지 부족이 큰 누수. |
| 대표 quote | "AI로 영어 학습 알지만 매번 켜서 상황 설명하기 귀찮잖아요. 여기는 결합돼서 편해요." (#02) |

**마케팅 함의**: 모수가 가장 크지만 LTV 약함. 옵션 비즈니스 특성상 페이드 ROAS 위험. 캐릭터/UI 차별화로 organic 입소문이 더 효율적일 수 있음. 결제 funnel UX(초대코드 동선·플랜 비교 표·튜토리얼) 개선이 단기 최대 ROI.

### 페르소나 3 — "출장형 지희" (업무영어 Need-on-Demand)
**근거**: #08 박지희, #04 염고운

| 차원 | 내용 |
|------|------|
| 핵심 니즈 | 출장·바이어·미팅 등 비정기 이벤트에서 영어 필요. 평소엔 안 씀. |
| 데모 correlate | 28–39세, 마케팅·무역 등 글로벌 접점 직무, 직장인 |
| 트리거 | 이벤트 임박 (미국 출장·바이어 방한). 끝나면 휴면. |
| 활성화 hook | "비즈니스 영어 + 일기 두 마리" |
| Retention 패턴 | Burst-and-fade. 30일 cohort retention 약함 예상. |
| 결제 의향 | **양극화**. 소득/연차에 따라 분리됨 (#08 39세 15년차 — 가격 부담 없음 / #04 28세 2년차 — 6,900원도 비싸다). |
| 대표 quote | "마음의 부채처럼 영어 콘텐츠 쌓아두는데, 베네핏이 즉시 안 나오니 열심히 안 하게 돼요." (#08) |

**마케팅 함의**: B2B 콜래보(글로벌 진출 SMB·무역 협회) 가능성. 단가가 가격을 못 견디는 #04 vs 부담 없는 #08의 차이는 연차/소득 — 광고 타겟팅에 직무 연차 변수 추가 검토.

## Korea ↔ Overseas 갭 (Hypothesis 섹션)

**검증된 사실**:
- 한국 페르소나 4종은 인터뷰 10건으로 검증.
- 해외 유저 정성 데이터 **없음**. 마케팅·결제 정량만 보유.

**합리적 hypothesis** (모두 검증 필요):

1. **언어 학습 동기의 차이**: US/CA/AU 결제자 일부는 한국어 학습자(이민 가정 자녀·K-콘텐츠 팬·교포 등)일 가능성. 컨설팅 대화에서 창업자가 언급한 "북미 한국어 학습자" 시장이 이미 organic하게 닿고 있을 수 있음. — **hypothesis, not validated**.
2. **소득·환율 효과**: ₩87k 12개월권은 USD 기준 ~$63로, 영어권 학습앱 평균 LTV 대비 저렴. 해외에서는 가격 진입장벽이 낮아 즉시 연간권 선택. — **hypothesis**.
3. **광고 카피 핏**: 인스타 광고가 한국 페르소나(자기효능감·일상) 중심으로 제작됐는데 영어권 광고 carry over 시 메시지 미스매치 가능. CTR 비교가 필요. — **hypothesis**.
4. **앱 자체의 한국어→영어 일기 흐름**이 한국어 학습자에겐 더 자연스러울 수 있음 (영어 표현 → 한국어 표현 연습). — **hypothesis**.

**다음 리서치 1순위**: 최근 30일 해외 결제자 5–10명 인터뷰. 특히 12개월권 선택자 우선. 언어 페어·기존 학습 도구·왜 즉시 연간을 끊었는지가 핵심 질문.
