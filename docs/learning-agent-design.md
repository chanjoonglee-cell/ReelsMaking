# 1장. 정의

## 1.1 에이전트란 무엇인가

### 고전적 정의 (AI 일반)
> **에이전트(Agent)** = 환경을 **인지(perceive)** 하고, 목표를 달성하기 위해 그 환경에 **자율적으로 행동(act)** 하는 시스템.
> — 인지→판단→행동의 루프를 *스스로* 돈다는 점이 핵심 (Russell & Norvig).

### LLM 시대의 재정의
LLM 에이전트는 **LLM을 추론 엔진(reasoning engine)으로 삼아, 자신의 제어 흐름(control flow)을 스스로 결정**하는 시스템이다. 즉 "다음에 무엇을 할지"를 코드의 `if/else`가 아니라 모델의 판단이 정한다.

### 에이전트 판별 기준 (4가지)
무언가가 "에이전트인가?"를 가르는 질문들:

| 기준 | 질문 | 에이전트라면 |
|---|---|---|
| **① 자율성** | 다음 행동을 누가 정하나? | **모델이 동적으로** 결정 (코드가 아님) |
| **② 목표지향** | 무엇을 향해 움직이나? | 명시된 목표 상태로 수렴 |
| **③ 상태/기억** | 과거를 기억하나? | 세션·장기 메모리 보유 |
| **④ 도구·환경** | 외부에 영향을 주나? | 도구 호출로 환경과 상호작용 |

### 에이전트가 *아닌* 것 (대조)

| 형태 | 왜 에이전트가 아닌가 |
|---|---|
| 단일 LLM 호출 | 무상태, 자율성·목표 없음 (입력→출력 1회) |
| 자동화/RPA·스크립트 | 흐름이 완전 고정, 판단 없음 |
| **워크플로우(LLM 파이프라인)** | LLM·도구를 쓰지만 **경로가 코드로 미리 정해짐** |
| 일반 챗봇 | 반응형 대화, 목표·계획·자기수정 없음 |

> **워크플로우 vs 에이전트** — 같은 부품(LLM+도구)을 써도, *경로를 코드가 정하면 워크플로우, 모델이 정하면 에이전트*. 이것이 우리가 가려는 **L1(LLMOps) → L2(Agent)** 의 본질.

### 성숙도 사다리 (현재 위치)

| 단계 | 특징 | 다음 행동 결정자 |
|---|---|---|
| L0 단일 호출 | 무상태 | 사람(프롬프트) |
| **L1 LLMOps 파이프라인** | 체이닝·관측·평가, **경로 고정** | 개발자(코드) ← *현재 우리 위치* |
| **L2 에이전트** | 상태+도구+**동적 행동 결정** | 에이전트 자신 ← *목표* |
| L3 다중 에이전트 | 역할 분담·위임 | 오케스트레이터 |

## 1.2 학습 에이전트란 무엇인가

위 일반 에이전트 정의를 **학습 도메인**에 투영한다.

| 일반 에이전트 | → 학습 에이전트 |
|---|---|
| 환경(environment) | **학습자**(그의 지식 상태·반응) |
| 목표(goal) | 학습자를 현재 수준 → 목표 역량으로 이동 |
| 인지(perceive) | 답변·발화·오답·반응시간을 **진단**으로 해석 |
| 행동(act) | 교수 활동(입력 제시·연습·교정·복습) 선택·실행 |

### 핵심: "학습"의 이중성
이 도메인에서 'learning'은 두 방향을 동시에 의미하며, **둘 다 있어야** 학습 에이전트다.

| | A. 가르치는 학습 (Teaching) | B. 배우는 학습 (Adaptation) |
|---|---|---|
| 주체 | 에이전트가 **사용자를** 학습시킴 | 에이전트가 **사용자에 대해** 학습함 |
| 산출 | 다음 학습 활동 | 갱신된 학습자 모델·전략 |
| 빠지면 | 개인화 없는 추천기 | 매번 리셋되는 정적 튜터봇 |

> **A↔B 두 루프가 맞물려 도는 것** = LLMOps를 넘어서는 결정적 지점. (대부분의 "AI 튜터"는 A만 있고 B가 없다.)

### 한 문장 정의
> **학습 에이전트** = 영속적 **학습자 모델**을 들고, 매 턴 학습자 신호를 **진단**해, 학습과학 원리를 행동 선택지로 삼아 **다음 학습 활동을 스스로 계획·실행**하고, 그 결과로 **학습자 모델과 전략을 갱신**하는 폐루프 시스템.

### 학습 에이전트 판별 기준 (4기준의 학습 도메인 투영)

| 기준 | 학습 에이전트에서 |
|---|---|
| ① 자율성 | "지금은 새 입력? 연습? 복습? 교정?"을 **스스로** 선택 |
| ② 목표지향 | ZPD/*i+1* 기준 목표 역량으로 수렴 |
| ③ 상태/기억 | **학습자 모델**(약점·이력·망각곡선) |
| ④ 도구·환경 | 콘텐츠 생성·채점·SRS 스케줄러·자료검색(RAG) |

### 학습 에이전트가 *아닌* 것
- **정적 튜터 챗봇**: 매 세션 리셋, 학습자 모델 없음 (B 결여)
- **문제 추천 시스템**: 개인화는 하나 교수 루프·자기수정 없음 (A 결여)
- **LLMOps 콘텐츠 생성 파이프라인**: 경로 고정, 동적 행동 결정 없음 (현재 우리 위치)

### 우리가 만들 것 (범위)
**언어학습 메커니즘을 코어로 하는 범용 학습 에이전트.** 언어학습의 검증된 원리(이해가능한 입력·출력강제·인출연습·간격반복·비계설정)를 **행동 선택지(action space)** 로 삼되, 구조 자체는 타 과목으로 일반화 가능하게 설계.
