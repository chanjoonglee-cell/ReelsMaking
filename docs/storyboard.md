# 언어의숲 — 숏폼 홍보 릴스 스토리보드

> 30초 세로형(1080×1920) Instagram Reels. 앱의 핵심 가치 "당신의 하루가 영어가 되는 순간"을 감성적으로 전달.

## 타깃 페르소나 — "지은"

| 항목 | 내용 |
|------|------|
| 나이/거주 | 28세, 서울 거주 직장인 |
| 영어 동기 | "공부"가 아니라 "삶의 기록"으로서의 영어. 시험점수가 아니라 매일 쓰는 습관이 목표 |
| 라이프스타일 | 한강 산책, 브런치, 카페 저널링, 아침 조깅, 독서, 요리 — 소소하지만 충만한 일상 |
| 성향 | 자기 성장에 진심, 꾸준함을 중시, 인스타로 일상·성취를 기록·공유 |
| 감성 무드 | warm + calm (따뜻하고 잔잔한, 햇살 가득한 톤) |
| 핵심 페인포인트 | 영어 공부가 지루하고 작심삼일 → "내 일상을 콘텐츠로 만들며 자연스럽게 영어가 늘면 좋겠다" |

## 컨셉 한 줄

> 사용자의 사진 + 영어 일기가 AI를 통해 한 편의 감성 릴스로 완성되는 과정을 보여주며,
> "꾸준한 기록이 곧 영어 실력이 된다"는 메시지를 전달한다.

## 5컷 구성 (총 30초)

| # | 시간 | 화면 | 자막(영문/한글) | 모션 | BGM |
|---|------|------|------------------|------|-----|
| **1 Hook** | 0–5s | 햇살 드는 카페, 지은이 폰으로 영어 일기를 쓰는 손/옆모습. 매트한 필름톤 | "What if writing one diary a day in English… changed everything?" | 슬로우 푸시인 + 햇살 보케 | warm, 잔잔한 피아노 인트로 |
| **2 일상 몽타주** | 5–13s | 한강 노을 → 아침 조깅 → 브런치 → 레몬파스타 요리. 사진이 폴라로이드 카드처럼 넘어감 | 일기 속 문장 자막 ("Today the sunset made me grateful…") | 카드 스와이프 / 가벼운 패럴랙스 | 비트 약간 상승 |
| **3 변환 마법 (UI)** | 13–21s | 앱 화면: 사진+일기 입력 → AI가 릴스로 변환되는 인터랙션 (Figma 디자인 반영 예정) | "언어의숲 AI가 당신의 하루를 30초 영상으로" | UI 요소 페이드/슬라이드, 진행바 애니메이션 | 빌드업 |
| **4 완성 & 성장** | 21–27s | 완성된 릴스를 폰으로 보며 미소짓는 지은. 화면 한쪽에 늘어나는 단어 수/연속기록 뱃지 | "30 days. 30 stories. A new you in English." | 화면 속 화면(폰 목업) + 살짝 줌아웃 | 감성 클라이맥스 |
| **5 로고 & CTA** | 27–30s | 다크 배경에 언어의숲 로고 등장 | "언어의숲 — 당신의 일상이 영어가 되는 곳" / "지금 시작하기" | 로고 페이드인 + 잎사귀 모션 | 잔향으로 마무리 |

## 제작 메모

- 톤앤매너: 따뜻한 노란빛, 부드러운 비네팅, 필름 그레인. 과한 채도 금지.
- Cut 3는 Figma 링크 공유 시 실제 UI 반영. 없으면 미니멀 목업으로 대체.
- 자막은 영문 메인 + 한글 보조(작게). 폰트는 가독성 높은 산세리프.
- 영상 생성: Cut별 키프레임 이미지 → 이미지-투-비디오. 사람 등장 컷은 일관된 룩 유지.
