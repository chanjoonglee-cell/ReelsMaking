## 1. 한 줄 전략

> **초대를 "프리미엄으로 가는 또 하나의 길"로 만든다.**
> 보상은 *친구 가입*이 아니라 **친구의 첫 결제(전환)** 에 건다. 그러면 추천인은 친구를 *결제까지 설득*하게 되고, 레퍼럴이 곧 유료 전환 엔진이 된다.

핵심 루프:

```
무료 유저 → [학습 완료, 성취감 ↑] → "프리미엄 더 누리고 싶다"
  → 초대 CTA: "친구에게 프리미엄 1개월 선물 + 나도 1개월"
  → 친구가 딥링크로 가입 (가입 전 가치 체험)
  → 친구 첫 결제  ←── ★유료 전환 발생
  → [지급] 양쪽 프리미엄 1개월
  → 추천인은 받은 프리미엄으로 더 오래 머묾(LTV) + 다음 친구도 초대(반복)
```

→ 친구 가입만으로는 큰 보상이 없으니, 추천인은 "친구를 **결제**시켜야" 보상받음 → 자연스럽게 프리미엄 가치를 친구에게 설득 → **전환율 상승**.

## 2. 어디서 (배치)

원칙: **"친구 초대" 메뉴를 설정 구석에 박지 마라.** 감정이 가장 높은 순간에 끼워 넣어야 한다. (듀오링고: 성취 공유 동선 → 레퍼럴 +116%)

| 순위 | 위치 | 역할 | 비고 |
|------|------|------|------|
| **①** | **학습 완료 직후 화면** | 성취감 피크에서 초대 제안 (메인) | 매번 ❌ → 좋은 점수·마일스톤·N회차 등 **성취 정점에만** 노출(스팸 방지) |
| **②** | **페이월 / 무료체험 만료 임박** | "결제 대신 친구 초대로 프리미엄 1개월" — 전환 직결 | 유료 전환 목표에 가장 직접적 |
| **③** | **스트릭 끊길 위기**(near-miss) | "조금만 더 하면 되는데" → 초대로 스트릭 프리즈 | 반복 초대 유발 (인당 초대자 수) |
| **④** | 스트릭/레벨 **마일스톤 달성** | 자랑하고 싶은 순간 → "친구와 함께" | 성취 공유 |
| ⑤ | 프로필/설정 상시 진입점 | 기본기(table stakes) | 드라이버 아님 |

→ **메인은 ① + ②.** ①(학습 완료 성취)에서 초대 *시도*를 만들고, ②(페이월)에서 *전환*에 직접 연결한다. ③은 반복 초대용.

## 3. 어떻게 (메커니즘)

- **인앱 초대 시트**: 개인 코드 + 딥링크, 카톡 원탭 공유 (30초 안에 끝나게 — SaaS 공통 교훈: 하나의 제안, 하나의 행동)
- **양방향 + 제품형 보상**: 추천인·피추천인 모두 **무료 구독 기간**. 현금·기프티콘·가격할인 ❌ (드롭박스 교훈: 제품형은 비용이 스케일 안 하고 좋은 유저만 self-select / 할인은 ARPU를 영구 잠식해 LTV↓)
- **선물 프레이밍**: "내가 받는다"보다 **"친구에게 프리미엄 1개월 선물"** 이 전환율 높음
- **딥링크**: 받는 친구는 가입 *전에* 가치를 먼저 경험 (기대감 + 즉시성)

### 3.1 확정 보상 구조 ("give a month, get a month" — IAP 기반)

| 대상 | 받는 것 | 트리거 |
|------|---------|--------|
| **피추천인**(초대받은 친구) | **1개월 무료체험** (IAP 자동갱신 구독, 결제수단 등록, 언제든 해지 가능, 미해지 시 1달 뒤 자동결제) | 딥링크/코드로 가입 + 스토어 결제 등록 |
| **추천인**(결제 유저) | **프리미엄 1개월 적립**(현 구독 연장) | 친구가 **유료 전환**(체험 후 첫 자동결제 성공) 시 확정 |

- 추천인은 *결제 유저*라 보상(무료 1개월)이 곧 **구독 연장 = LTV↑**
- 친구 체험 시작 시점엔 "곧 지급 예정"으로 표시 → 추천인 동기 유지, **확정 지급은 첫 결제 성공 후**(쿨링오프 경과)
- **약정 강제 안 함**(3/6/12개월 강제는 수용률↓). 대신 **길게 등록할수록 보너스**로 유도(예: 연간 등록 시 친구에게 1→2개월)
- 추천인 **누적 상한**: 연 최대 12개월(무한 스택 방지)

### 3.2 마일스톤 티어 (B안의 '모으는 재미'를 할인 없이 흡수)

문턱(threshold)이 아니라 **가산형**으로. (리서치: 티어드 구조 → 반복 레퍼럴 +41%)
- 친구 1명 전환 = 1개월 / 2명 = 누적 2개월 + 뱃지 / **3명 누적 = 보너스 1개월**
- 핵심: 3명이 *조건*이 아니라 *보너스* → 2명에서 멈춰도 이미 2개월 확보 → 포기 안 함

### 3.3 IAP 실무 제약 (구현 전 확인)

- **무료체험 1회 제한**: 애플/구글은 *계정당 구독그룹별 무료체험 1회*만 허용 → 이미 체험 쓴 유저는 스토어 intro offer 불가 (오퍼코드/서버 entitlement로 우회 검토)
- **추천인 무료 1개월 지급 방식**: 기존 구독자에게 무료 기간 부여 → App Store 오퍼코드/프로모셔널 오퍼, Google Play 프로모 코드, 또는 **서버 측 entitlement**(예: RevenueCat)로 처리
- **스토어 수수료**: 구글플레이 자동갱신 15%, 애플 15~30% → 단위경제(LTV/CAC) 계산에 반영
- **정책**: 구글은 리퍼럴/로열티 보상 허용하되 "결제에 부수적"이어야 함 → 약관·정책 적합성 사전 확인
- **환불/해지 회수**: App Store Server Notifications / Google Play RTDN으로 환불·즉시해지 감지 → 추천인 적립 회수
- **어뷰징(이점)**: IAP는 애플/구글 ID에 묶여 다계정 어뷰징이 더 어려움

### 3.4 세그먼트별 2-트랙 (결제 유저 vs 무료 유저)

추천인이 결제 유저냐 무료 유저냐에 따라 *동기가 다르다* → 트랙을 나눈다.

| | **트랙1: 결제 유저 → 1:1 레퍼럴** | **트랙2: 무료 유저 → 공동구매** |
|---|---|---|
| 메커니즘 | give a month / get a month | 친구 2~3명 모아 함께 시작 → 전원 인트로 할인 |
| 왜 이 세그먼트에 맞나 | "구독 연장"이 보상으로 의미 있음 | 연장할 구독이 없음 → "함께 싸게 시작"이 동기 |
| 보상 | 무료 1개월(구독 연장) | 첫 결제(또는 첫 3개월) **인트로 할인** |
| 목표 | payer LTV↑ + 신규 payer 획득 | **무료 클러스터 동시 전환** |
| 검증 | 듀오링고/Busuu/Babbel | 핀둬둬(최저 CAC)/듀오링고 패밀리 |

**할인의 두 종류 — 반드시 구분:**
- ❌ 영구 월 할인(8,900→6,900 계속) = ARPU 영구 잠식 = LTV↓ → 채택 안 함
- ✅ 공동구매 **인트로 할인**(첫 결제/첫 N개월만, 이후 정상가) = 획득 비용 성격 → 채택

**공동구매 설계 원칙:**
1. **소규모(2~3명) + 마감 카운트다운(24~48h)** → 어반던 ↓, 긴급성(=near-miss) ↑ (핀둬둬 엔진)
2. **그룹 미충족 시 솔로 폴백**(작은 체험이라도) → all-or-nothing 함정 회피
3. **인트로 할인 시간제한** → 종료 후 정상가, 리텐션은 1:1 레퍼럴 무료월이 담당
4. **IAP**: 인트로 오퍼 + 그룹 충족 시 서버 entitlement로 할인 부여

---

## 4. CAC ↓ / LTV ↑ 에 어떻게 꽂히나

**CAC ↓**
- 보상을 **결제 전환 시점에만** 지급 → 사실상 **성과형 획득비용**. 광고 CPI처럼 미전환 유저에 돈을 태우지 않음
- 보상이 제품형(무료 구독일)이라 한계비용 낮음
- 추천 경로 유입 유저는 리텐션이 높아 **LTV 대비 실질 CAC**가 더 낮아짐

**LTV ↑**
- 추천으로 온 유저 = 지인 연결 → **리텐션 ↑**
- 추천인은 보상받은 **무료 프리미엄 기간만큼 더 머묾** + 초대 행위 자체가 커밋
- 무료 구독일 = 학습 시간 ↑ = **습관 형성**(언어 학습 리텐션의 핵심)

## 5. 어뷰징 방어 (요지)
- **신규 유저만** 피추천인 자격 / **자기 초대 차단**(동일 기기·결제수단·IP)
- 큰 보상은 **첫 결제 + 환불기간 경과 후** 지급 (review window)
- 한 추천인에서 가입 급증, 데이터센터 IP/VPN, 낮은 사용시간 → 플래그
- 추천인 **보상 상한**(예: 연 최대 12개월치)

## 6. 측정 — K를 항별로
| 레버 | 지표 |
|------|------|
| 공유 시도율 | 완료 화면 초대 노출 → 공유 클릭 |
| 공유 성공률 | 링크 열람률 → 가입 전환율 |
| 인당 초대자 수 | 추천인당 **결제 전환된** 친구 수 |
| ★전환 | **초대 경유 가입 → 첫 결제 전환율** (1차 목표 KPI) |

퍼널: `학습 완료 → 초대 노출 → 공유 → 링크 열람 → 가입 → 무료체험 → 첫 결제`
(Mixpanel 연동되어 있어 그대로 이벤트 설계 가능)

## 7. 단계적 출시 (Crawl → Walk → Run)
- **Crawl** — 학습 완료 화면(①) 초대 + 양방향 제품형 보상 + 첫 결제 트리거. 전환율 베이스라인 측정
- **Walk** — 페이월(②) 연계, 딥링크 가입 전 체험, 선물 프레이밍 A/B
- **Run** — 반복 엔진(③ 스트릭 near-miss)으로 인당 초대자 수 공략

## 8. 결정 현황

**확정**
- 보상 = "give a month, get a month" (양방향 무료 1개월, 제품형)
- 피추천인 = IAP 1개월 무료체험(결제등록, 언제든 해지, 미해지 시 자동결제)
- 추천인 = 친구 첫 결제(유료 전환) 시 1개월 적립, 연 최대 12개월
- 결제 유저 = 1:1 레퍼럴 / 무료 유저 = 공동구매(인트로 할인) **2-트랙**
- **영구** 월 할인은 폐기(LTV↓), 단 **공동구매 인트로 할인**은 채택(획득비용 성격)

**아직 결정 필요**
1. **마일스톤 티어** 채택 여부 및 보너스 크기 (권고: 3명 누적 +1개월)
2. **약정 보너스** — 연간 등록 시 친구 보너스 1→2개월 줄지
3. **반복 엔진(레버③)** — 학습 스트릭 vs 점수 챌린지 (권고: 스트릭)
4. **완료 화면 노출 규칙** — 매번 vs 성취 정점에만 (권고: 정점 + 빈도 제한)
5. **딥링크 인프라** — Branch.io / AppsFlyer / 자체 (Firebase Dynamic Links 2025 종료)
6. **IAP 무료 1개월 지급 방식** — 오퍼코드 vs 서버 entitlement(RevenueCat 등)

## 부록 A. 언어학습 앱 레퍼럴 벤치마크

| 앱 | 추천인 보상 | 피추천인 보상 | 트리거 | 상한 |
|----|------------|--------------|--------|------|
| **Duolingo** | Super 1주 무료 | Super 1주 무료 | 친구 **가입**(링크) | Super days 누적 |
| **Busuu** | 친구당 프리미엄 1개월 | 30일 프리미엄 체험 | **가입**(링크) | **12명 = 최대 1년** |
| **Babbel** | **€10 선불카드**(현금성) | 1개월 무료 | 친구가 **3개월+ 결제** | — |
| Memrise/Mondly | (소비자 레퍼럴 아님 — 제휴 15~30% 커미션) | — | — | — |
| Cake/Speak/산타(한국) | 상시 레퍼럴 공개정보 적음 — 무료체험·시즌 프로모·법인(B2B) 위주 | | | |

비교군(타 업종): 드롭박스 = 제품형(저장공간) 양방향, 3900% 성장 / PayPal = 현금 $20+$20, $60M 소진.

**패턴**
1. 거의 모두 **양방향** 보상
2. 보상 = **무료 구독 기간(제품형)이 주류** (Babbel만 추천인 현금 — 소수파)
3. **상한 존재** (Busuu 12명/1년 ← 우리 "연 12개월"과 동일)
4. **전환 게이팅 분기**: 듀오링고·Busuu=가입 기준(저마찰) / Babbel=다년 결제 기준(고의도)
5. **배치 = 프로필 + 성취 공유 모먼트** (듀오링고 성취 공유 → +116%)

**우리 확정안의 위치**: Babbel의 *전환 게이팅*(친구 결제 시 지급) + 듀오링고/Busuu의 *제품형 무료 기간 보상* 을 결합하고, Babbel의 현금 카드는 회피(드롭박스 교훈). → 업계 베스트 조합.

**한국 시장 시사점**: 메이저 영어앱들이 상시 인앱 레퍼럴이 약하고 무료체험·프로모·퍼포먼스 광고·B2B에 의존 → **잘 설계된 인앱 레퍼럴 자체가 차별화 + CAC 절감 채널**.

## 부록 B. 추가 제안 (백로그)

확정 플로우(`referral-flow.md`) 위에 얹어볼 만한 아이디어. 우선순위 순.

### B1. 무료 유저 트랙 = 공동구매 (본문 §3.4에서 채택) ★
- 무료 유저는 "구독 연장"이 의미 없음 → **친구 2~3명 모아 함께 인트로 할인으로 시작**(공동구매)
- 무료 클러스터를 한 번에 전환 + 핀둬둬식 최저 CAC
- (대안/병행) 무료 유저가 1:1 초대 → 친구 전환 시 본인에게 프리미엄 1개월 부여 → 본인 전환 미끼. A/B로 공동구매와 비교 가능

### B2. 소셜 학습 (함께 스트릭 / 프렌즈 퀘스트) ★LTV 최강
- 듀오링고 Friends Quest / 패밀리 플랜 스타일 — 초대한 친구와 **공동 스트릭·친구 리더보드**
- 초대가 일회성 이벤트가 아니라 **지속 인게이지먼트**가 됨 → 양쪽 리텐션↑ (LTV↑)
- 동시에 레버③(반복하고 싶은 아쉬움)을 자연 충족 — "친구가 기다린다"는 압박

### B3. 선물(Gifting) 트랙 — 바이럴 + 추가 매출
- "친구에게 프리미엄 1개월 **선물하기**"를 유료 상품으로도 제공
- 레퍼럴(무료 획득)과 별개로 **직접 매출** 발생 + 받은 친구는 전환 후보
- 명절·시즌 캠페인과 결합 용이

### B4. 이탈 방지(win-back)에 레퍼럴 결합
- 해지 플로우에서 "해지 대신 **친구 초대하고 1개월 더 받기**" 제안
- 효과: churn↓ + 이탈 직전 유저를 추천인으로 전환

### B5. 마일스톤 진행바 (near-miss 시각화) — 레버③ 강화
- "친구 2명 전환 · 1명 더 모으면 보너스 1개월" **진행바** 상시 노출
- 토스 '한글날 챌린지'의 "조금만 더 하면" 심리를 시각화 → 인당 초대자 수↑

### B6. 온보딩 코드 입력란 (기본기, 누수 방지)
- 신규 가입 온보딩에 "초대 코드 있나요?" 입력란
- 딥링크 실패·수동 공유 케이스의 **attribution 누수 방지** + 입력 시 즉시 체험 보너스

### B7. 상시 A/B 실험 인프라
- Mixpanel + feature flag로 **보상 크기·문구·배치**를 상시 실험 (이미 MCP 연동)
- 시즌별 더블 보상 캠페인으로 K를 의도적으로 끌어올리기(토스식 단계적 상향)

### B8. 변동/미스터리 보상 (토스 복권 + 로빈후드 랜덤 주식)
- 고정 "1개월"을 **"최대 3개월 중 랜덤"** 또는 미스터리 박스로 → 변동 보상의 기대감
- 즉시 결과 확인(즉시성) → 열람·전환↑. 고정 vs 변동 **A/B 권장**

### B9. 초대 시트 '잠재수익 표시' (레볼루트)
- "이 친구 3명 초대하면 **최대 3개월 무료**" 처럼 *벌 수 있는 양*을 명시 → 초대 동기↑

## 부록 C. 그로스 메커니즘 딥다이브 (벤치마크)

| 회사 | 핵심 메커니즘 | 우리가 훔칠 점 |
|------|--------------|---------------|
| **핀둬둬** | 공동구매(그룹 충족 시 전원 할인) · 砍价(24h 내 친구 클릭마다 할인 누적→0원) · 둬둬 과수원(미션=초대로 실물 보상) | **시간제한 + near-miss 진행바**, 모든 진도에 초대를 끼움 |
| **듀오링고** | 스트릭(커밋 +60%) · **친구 스트릭**(상호 책임) · 배지(레퍼럴 +116%) · 리그(인게이지 +40%) · **여정 단계별 계층형 훅** | 공동 학습 스트릭, 단계별 초대 배치 |
| **로빈후드** | 대기열 순위 레퍼럴 + **랜덤 주식($2.5~225) 양방향** → 출시 전 100만 | **변동 보상**(=토스 복권), 진행 시각화 |
| **레볼루트** | 양방향 700% 성장 · **친구 카드결제 3회 후 보상 확정** · 시간제한 FOMO · **잠재수익 표시** | 깊은 활성화 게이트, 잠재수익 UI |

**토스 케이스 추가 교훈(미사용분):**
1. **측정 → 병목 한 개씩 공략** (K 0.2→0.4→0.7→0.9) — 한꺼번에 만들지 말 것 (= Crawl-Walk-Run 근거)
2. **변동/미스터리 보상**이 기대감을 만든다 (복권 = 로빈후드 랜덤주식과 동일 원리) → B8
3. **받는 친구가 비유저여도 재밌어야** — 초대받은 사람 경험이 그 자체로 흥미로워야 함

**수렴 포인트**: 듀오링고 친구 스트릭 = B2(소셜 학습) = 토스 레버③(반복) → 무료 유저는 *공동구매로 함께 시작* → *친구 스트릭으로 함께 유지* → 전환→리텐션이 한 흐름.
