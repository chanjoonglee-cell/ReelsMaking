## 1. 한눈에 보는 플로우

```
[추천인 · 결제 유저]
  ┌─────────────────────────────────────┐
  │ 학습 완료 화면 (성취감 피크)         │  ← 메인 진입점
  │  "친구에게 프리미엄 1개월 선물        │  (+ 페이월 / 스트릭 위기 보조 진입점)
  │   + 나도 1개월"                      │
  └──────────────┬──────────────────────┘
                 │ 초대 시트(개인코드 + 딥링크)
                 │ 카톡 원탭 공유 (30초)
                 ▼
          ┌──────────────┐
          │  [피추천인]   │
          │ 딥링크 클릭   │
          └──────┬───────┘
                 ▼
        앱 설치/열기 → 코드 자동 귀속(attribution)
                 │  (가입 전 가치 미리보기 = 기대감)
                 ▼
        가입 + IAP 1개월 무료체험 등록 ──▶ 추천인 화면: "보상 지급 예정"(pending)
                 │  (결제수단 등록 · 언제든 해지 가능)
                 ▼
        1개월 체험 (학습 가치 경험)
                 │
                 ▼
        ★ 첫 자동결제 성공 = 유료 전환(qualified)
                 │
       ┌─────────┴───────────────────────────┐
       ▼                                     ▼
 추천인: 프리미엄 1개월 확정 지급       피추천인: 유료 구독 시작
 (현 구독 연장 · 연 최대 12개월)
       │
       ▼
 다음 친구 초대 → 반복 (마일스톤 진행바로 near-miss 자극)
```

## 2. 단계별 상세

| # | 단계 | 추천인 | 시스템 | 피추천인 |
|---|------|--------|--------|----------|
| 1 | 트리거 | 학습 완료(성취 정점)에서 초대 CTA 노출 | 성취 정점 + 빈도제한 룰로 노출 | — |
| 2 | 공유 | 코드+딥링크 카톡 공유 | 코드 발급, 딥링크 생성 | — |
| 3 | 귀속 | — | 딥링크 클릭 → 코드 attribution 저장(30일 윈도) | 링크 클릭, 가치 미리보기 |
| 4 | 가입·체험 | "지급 예정" 표시 | 신규 유저 검증, IAP 체험 시작 기록 | 가입 + IAP 1개월 무료체험 등록 |
| 5 | 전환 | — | 첫 결제 웹훅 수신(멱등 처리), 쿨링오프 카운트 | 체험 후 첫 자동결제(=전환) |
| 6 | 지급 | **프리미엄 1개월 확정**(구독 연장) | 양방향 보상 grant, 캡 체크 | 유료 구독 지속 |
| 7 | 반복 | 마일스톤 진행바 확인 → 다음 초대 | 누적 전환 수 집계, 티어 보너스 | — |

## 3. 상태 머신

```
invited(코드발급)
   → attributed(딥링크 귀속, 30일 윈도)
   → signed_up(가입 + IAP 체험 등록)
   → converted(체험 후 첫 결제 = 유료 전환 = qualified)
   → rewarded(양방향 1개월 지급)
   → (환불/쿨링오프 내 해지 시) reverted(보상 회수)
```

핵심 분기: **signed_up ≠ 보상 확정.** 보상은 항상 `converted` 이후. (어뷰징 방어 + 유료 전환 정렬)

## 4. 보상 지급 타임라인

| 시점 | 피추천인 | 추천인 |
|------|----------|--------|
| T0 (가입+체험등록) | 프리미엄 1개월 무료체험 **즉시** 시작 | "보상 지급 예정"(pending) 표시 |
| T+1개월 (첫 결제 성공) | 유료 구독 전환 | 프리미엄 **1개월 확정** 지급 |
| 환불/쿨링오프 내 해지 | 체험·구독 종료 | 적립 **회수**(reverted) |

## 4-B. 트랙2 플로우 — 무료 유저 공동구매

```
[무료 유저]
  페이월 / 가격 화면
     │ "친구 2명과 함께 시작하면 첫 3개월 할인"
     ▼
  공동구매 그룹 생성 (코드+딥링크 공유) ──▶ [친구들]
     │  ⏳ 마감 카운트다운(24~48h)               딥링크 클릭 → 합류
     ▼
  그룹 충족(2~3명) ?
     ├─ 예 → 전원 인트로 할인가로 구독 시작(IAP) = ★동시 전환
     │         └ 인트로 종료 후 정상가 → 이후 1:1 레퍼럴 무료월이 리텐션 담당
     └─ 아니오(마감) → 솔로 폴백(작은 체험 제공, 빈손 방지)
```

상태: `group_created → (member_joined)* → fulfilled(전원 전환) | expired(솔로 폴백)`

## 5. 예외 / 엣지 흐름

- **체험 중 해지(미결제)** → 전환 아님 → 추천인 미지급 (정상)
- **이미 무료체험 쓴 피추천인** → 스토어 intro offer 1회 제한 → 오퍼코드/서버 entitlement로 대체 혜택
- **무료 유저가 추천인** → (정책 선택) 적립해뒀다 본인 구독 시 적용 *또는* 즉시 프리미엄 1개월 부여(= 추천인 본인 전환 미끼) ※ 부록 '추가 제안' 참고
- **자기 초대 / 다계정** → 동일 결제계정·기기·IP 군집 차단 (IAP는 계정 묶임이라 방어 유리)
- **귀속 만료** → 클릭 후 30일 경과 가입은 미귀속
- **상한 초과** → 연 12개월 적립 한도 도달 시 추가 보상 보류/안내
- **결제 웹훅 중복** → idempotency key로 중복 지급 방지
