## 배경

### 문제 의식

- 우리 타겟은 **"환경적으로 영어를 잘해야 / 잘하고 싶은데, 방법은 모르겠고, 실용적인 영어가 필요한 사람"** — 넓은 학습 수요층
    - 언어의숲은 **쉽고 · 친절하고 · 실용적**이라 이들이 *자주(습관적으로)* 사용 → 제품-시장 적합성이 강함
    - 그중 **해외 거주 교민**은 *생존을 위해* 공부해야 해서 결제율이 **약 3배** 높은 고가치 하위 세그먼트
- 문제 ① 유료 전환 경로가 **페이월(가격 노출) 하나**에 의존 → 가치 체감 전에 가격부터 만나 이탈, 전환율 상방이 막힘
- 문제 ② 신규 유저 확보를 **유료 광고에 의존** → CAC 상승 (해외 타겟은 단가↑·정밀 타게팅 어려움)
- 그러나 "쉽고 좋아서 자주 쓰는" 제품은 본래 **입소문(지인 추천)으로 퍼지기 좋은데**, 제품 안에 그 입소문을 전환으로 잇는 장치가 없음
    - 특히 교민은 커뮤니티 밀도가 높아(카톡 단톡방 · 교민 카페 · 교회 · 학부모 모임) 한 번 퍼지면 빠르게 확산

### ⇒ 따라서 지인 추천(입소문)을 유료 전환으로 잇는 **인앱 레퍼럴 기능**을 제안함

> 핵심은 **'초대'** 다. 거래(현금·포인트)가 아니라 **"함께 공부하자 / 좋은 앱이라 추천"** 하는 *진심 공유*로 설계한다.
> 보상은 *친구 가입*이 아니라 **친구의 첫 결제(전환)** 에 걸어, 레퍼럴이 곧 **유료 전환 엔진**이 되게 한다.
> 제품이 "함께하는 습관 · 멘탈케어"라 이 정서적 프레이밍이 타겟과 맞아떨어진다.

---

## 기대 효과

1. **유료 전환율 ↑** — 페이월 외 두 번째 전환 경로. 지인 신뢰 기반이라 광고보다 전환율 높음
2. **CAC ↓** — 교민 커뮤니티(카톡·카페·교회)를 통한 유기적 확산, 광고 대비 저렴
3. **LTV / 리텐션 ↑** — 함께 학습 = 습관·정서 효용 ↑. 추천인은 보상으로 구독 연장(유료) / 본인 전환(무료)
4. **핵심 세그먼트(해외 교민) 침투** — 하나의 커뮤니티에 깊게 확산(밀도 높은 바이럴)

## 스토리보드

> 🎯 **타겟 페르소나**
>
> - **페르소나 1 (메인):** 영어가 *필요한 환경*에 놓였지만 방법을 몰라 막막한 30~40대 학습자(직장인 등). "실용적인 영어를 당장 써야 함." 언어의숲이 쉽고 친절하고 실용적이라 자주 사용 → 만족도가 높아 지인에게 추천할 동기가 큼.
> - **페르소나 2 (고가치 하위 세그먼트, SOM):** 해외 거주 중년 여성 한인교민. *생존*을 위해 공부해야 해서 결제율 **약 3배**. 회사·자녀학교·병원에서 매일 영어가 필요, 아침·밤 10분 학습, 모국어 일기로 정서 회복 → 영어의숲을 *습관성 멘탈케어 앱*으로 인식. **커뮤니티(카톡·카페·교회·학부모모임) 밀도가 높아 추천 확산이 빠름.**
> - **페르소나 3 (피추천인 / 무료 유저):** 지인 추천으로 유입했거나, 가입했지만 아직 결제하지 않은 유저. 가입 전·직후 가치를 먼저 체감하면 결제 장벽이 낮음.

| 시나리오 | **유료유저 레퍼럴** | **무료유저 레퍼럴** |
| --- | --- | --- |
| **도달** | 추천인(유료)이 지인(친구·동료·가족, 교민 커뮤니티)에 **딥링크/코드** 공유 | 추천인(무료)이 동일 |
| **인지 (Awareness)** | "○○님이 **함께 공부하자**며 영어의숲 초대 / 1개월 무료" | (동일) |
| **유입 (Acquisition)** | 딥링크 → 앱 설치/실행 → 기존 결제 플로우 진입 | (동일) |
| **활성 (Activation)** | 친구: **1개월 무료 구독** 시작 (이후 인트로가 → 정가) | (동일) |
| **(운영)** | 결제수단/기기 dedup + 의심건 수동검수. **친구 첫 결제까지 보상 홀드** | (동일) |
| **재방문 (Retention)** | 친구: 무료 기간 아침·밤 학습 습관 → 유료 전환. 추천인: 보상(연장) 확인차 재방문 | 추천인(무료): 초대·할인 진행 확인차 재방문 → **본인도 전환** |
| **추천 (Referral)** | 노출 = **학습 완료 직후** / 친구 전환당 **내 구독 +1개월** | 노출 = **가입 +3일·프로모션 후** / 초대 시 **본인 전환 할인 ↑** → 결제하면 **유료 레퍼럴로 승급** |

### 가격 (확정)

| | 가격 | 비고 |
| --- | --- | --- |
| 정가 | **월 8,900원** | 인상될 가격 |
| 레퍼럴 친구 인트로가 | **월 6,900원** | −22%, 🟡 기본 3개월 한정 후 정가 (영구할인 ❌) |

> 친구 가격 여정: **1개월 무료체험 → 인트로 6,900원/3개월 → 정가 8,900원**

### 두 엔진 요약

| | **① 유료유저 레퍼럴** | **② 무료유저 레퍼럴** |
| --- | --- | --- |
| 추천인 | 결제 중인 유저 | 무료 유저 (첫 가입 **+3일 프로모션 후**) |
| 초대 대상(친구) | 무료 유저(지인) | 지인 |
| **추천인 보상** | 친구 전환당 구독 **+1개월** (스택, 연 12개월 상한) | 본인 전환 시 **더 깊은 할인** (초대할수록 ↑) 🟡 단계 |
| **친구 보상** | **1개월 무료 구독** 🟡(조건 "다만 …" 확인) → 이후 인트로 6,900원 | (피추천인은 유료 레퍼럴과 동일 경로) |
| 본질 | LTV 연장 + 신규 유입 | 무료유저 **본인 전환 미끼** |
| 전환 후 | — | 결제하면 **① 유료 레퍼럴로 승급** |

> **두 엔진의 공통 심장 = '초대'.** 둘 다 "함께 공부하자 / 좋은 앱이라 진심으로 추천"이라는 동기로 작동.
> 무료 유저는 초대를 통해 *본인이 더 싸게 전환*할 길이 생기고, 결제하는 순간 *친구를 모으면 개월수를 버는* 유료 엔진으로 넘어간다 → **하나의 연속된 전환 깔때기.**
> 친구가 겪는 퍼널(도달~재방문)은 양쪽 동일, 갈리는 건 **추천인 쪽(노출·보상·다음 단계)** 뿐.

### 논의 필요 지점

1. 🟡 **무료 엔진 할인 단계** — 초대 1·2·3명 → 본인 전환 시 할인 폭(얼마나 깊게)
2. 🟡 **유료 엔진 +1개월 스택 규칙** — 친구 전환당 +1개월, 동시 진행/누적/연 12개월 상한 처리
3. 🟡 **친구 "1개월 무료 구독" 조건** — 카드 등록 필요 여부 등 ("다만 …" 잘린 부분 확인)
4. 🟡 **노출 규칙** — 완료 화면 매번 노출 ❌ → 권고: **성취 정점 + 7일 1회 상한**
5. 🟡 **신규 친구 정의 / 어트리뷰션** — 완전 신규만? 휴면·재설치 처리? 딥링크 vs 코드 우선순위
6. 🟡 **보상 회수(claw-back)** — 친구가 환불/차지백하면 추천인 보상 회수하나
7. 🟡 **상한·약관** — 연 12개월 외 월/일 상한 + **자동결제·이벤트 약관 고지** (⚠️ 해외 교민 타겟 → 미국 등 자동갱신 고지법 대응 필요)
8. 🟡 **인트로 기간 N=3개월** 확정 여부
9. 🟡 **MVP 범위** — 풀자동 전에 **수동 초대코드 + 어드민 수동 보상지급**으로 소규모 검증할지 (아래)

## 기술 검토 필요 지점

> ⚠️ 플랫폼: **iOS / Android 둘 다**, 결제 플로우는 **이미 보유**.

1. **딥링크 어트리뷰션** — Branch.io / AppsFlyer (Firebase Dynamic Links 2025 종료). ⚠️ 해외 다국가 환경 대응 필요
2. **IAP 무료개월 지급** — iOS 프로모션 오퍼/오퍼코드 + Android 프로모션 코드, 또는 **RevenueCat 등 서버 entitlement로 양 OS 통합**
3. **어뷰징 탐지** — 결제수단/기기/IP dedup, 자기초대(다계정) 차단. ⚠️ 국가 간 결제수단 식별 정확도
4. **추천관계 트래킹 DB + 보상 상태머신** — 카운트 → (친구 첫 결제까지) 홀드 → 지급 / 회수
5. **어드민 기능** — 수동 검수, 보상 회수, 진행률·히스토리(마이페이지)

### (추가) 성공 지표 (KPI)

- **K-factor** (초대당 신규 유입)
- 초대 → **적격 전환율**, 적격 → **첫 결제 전환율**
- **레퍼럴 CAC vs 광고 CAC**
- 추천 경유 유저 **D30 리텐션** vs 일반 유입
