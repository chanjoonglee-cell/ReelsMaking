## 배경

### 문제 의식

- 현재 유료 전환 경로가 **페이월(가격 노출) 하나**에 의존 → 전환율의 상방이 막혀 있음
    - 무료 유저가 프리미엄 가치를 *직접 체감*하기 전에 가격부터 만나 이탈
- 신규 유저 확보를 **유료 광고에 의존** → CAC 상승
    - 특히 핵심 타겟이 해외 거주 교민이라 광고 단가가 높고 정밀 타게팅이 어려움
- 그러나 우리의 **최고 결제 세그먼트(SOM: 해외 거주 중년 여성 한인교민)는 이미 강한 추천 네트워크 위에 있음**
    - 결제율이 국내 대비 **2.7배** — 한 명이 좋다고 하면 주변이 따라 결제하는 **신뢰 자본**이 큼
    - 이들은 끈끈한 커뮤니티에 묶여 있음: **카톡 단톡방 · 네이버 교민 카페 · 교회/성당 · 자녀 학교 학부모 모임**
    - 제품 본질이 *"습관성 멘탈케어"* (외로운 해외생활에서 아침·밤 10분 영어 일기 = 정서 회복) → **혼자보다 함께할 때** 리텐션·정서적 효용이 커지는 구조
- 즉, **가장 전환이 잘 되는 유저들이 이미 강한 추천 네트워크 위에 있는데, 이를 제품 안에서 활용하는 장치가 없음**

### ⇒ 따라서 교민 커뮤니티의 신뢰를 유료 전환으로 잇는 **인앱 레퍼럴 기능**을 제안함

> 핵심 원리: 보상을 *친구 가입*이 아니라 **친구의 첫 결제(전환)** 에 건다.
> 그러면 추천인은 친구를 *결제까지 설득*하게 되고, 레퍼럴이 곧 **유료 전환 엔진**이 된다.
> 제품이 "함께하는 멘탈케어"라, **"친구에게 영어습관을 선물한다"** 는 프레이밍이 타겟 정서와 맞아떨어짐.

## 기대 효과

1. **유료 전환율 ↑** — 페이월 외 두 번째 전환 경로. 지인 신뢰 기반이라 광고보다 전환율 높음
2. **CAC ↓** — 교민 커뮤니티(카톡·카페·교회)를 통한 유기적 확산, 광고 대비 저렴
3. **LTV / 리텐션 ↑** — 함께 학습 = 습관·정서 효용 ↑. 추천인은 보상으로 구독 연장(유료) / 본인 전환(무료)
4. **핵심 세그먼트(해외 교민) 침투** — 하나의 커뮤니티에 깊게 확산(밀도 높은 바이럴)

## 스토리보드

> 🎯 **타겟 페르소나**
>
> - **페르소나 1 (SOM, 메인):** 미국 거주 40대 후반 한인 교민 여성. 회사·자녀 학교·병원에서 매일 영어가 필요해 계절성 없이 학습. 아침(출근 전)·밤(취침 전) 집에서 1회 10분 내외. 모국어 일기로 정서 회복 → 영어의숲을 *습관성 멘탈케어 앱*으로 인식. **이미 결제 중인 유료 유저이자, 같은 커뮤니티에 추천할 힘이 가장 큰 추천인.**
> - **페르소나 2 (피추천인):** 같은 교민 카페/교회/단톡방의 또 다른 중년 여성. "○○님이 좋다더라"는 지인 신뢰로 유입 → 가입 전 가치를 먼저 체감하면 결제 장벽이 낮음.
> - **페르소나 3 (무료 추천인):** 가입은 했으나 아직 결제하지 않은 교민. 프리미엄을 직접 못 써봐서 망설이는 중 → 친구 3명을 데려오면 프리미엄을 *맛보기* 하고 본인도 전환.

| 시나리오 | **유료유저 레퍼럴** | **무료유저 레퍼럴** |
| --- | --- | --- |
| **도달** | 추천인(유료)이 교민 카톡/카페/직접 만남에서 **딥링크/코드** 공유 | 추천인(무료)이 동일 채널로 공유 |
| **인지 (Awareness)** | "친구가 영어의숲 **프리미엄 1개월을 선물**했어요" | (동일) |
| **유입 (Acquisition)** | 딥링크 → 앱 설치/실행 → 기존 결제 플로우 진입 | (동일) |
| **활성 (Activation)** | **카드 등록 + 1개월 무료체험** + 인트로 6,900원/3개월 → **적격 1명** 충족 | (동일) → 적격이 **3명** 모이면 추천인 보상 |
| **(운영)** | 결제수단/기기 dedup + 의심건 수동검수. **친구 첫 결제까지 보상 홀드** | (동일) |
| **재방문 (Retention)** | 친구: 체험 중 아침·밤 학습 습관 → 정가 전환. 추천인: 구독 연장 확인차 재방문 | 친구: (동일). 추천인: **진행률(3명 중 n명)** 확인차 재방문 |
| **추천 (Referral)** | 노출 = **학습 완료 직후** / 문턱 **1명** / 보상 = 내 구독 **1개월 연장** | 노출 = **가입 +3일·프로모션 후** / 문턱 **3명** / 보상 = 프리미엄 **1개월 증정** |

### 가격 (확정)

| | 가격 | 비고 |
| --- | --- | --- |
| 정가 | **월 8,900원** | 인상될 가격 |
| 레퍼럴 친구 인트로가 | **월 6,900원** | −22%, 🟡 기본 3개월 한정 후 정가 (영구할인 ❌) |

> 친구 가격 여정: **1개월 무료체험 → 인트로 6,900원/3개월 → 정가 8,900원**

### 두 엔진 요약

| | **① 유료유저** | **② 무료유저** |
| --- | --- | --- |
| 추천인 상태 | 결제 중 | 미결제 |
| 문턱 | 적격 **1명** | 적격 **3명** |
| 추천인 보상 | 구독 **1개월 연장** | 프리미엄 **1개월 증정** |
| 본질 | LTV 방어/연장 | 본인 **전환 미끼** |
| 상한 | 연 12개월 | 연 12개월 |

→ 친구가 겪는 퍼널(도달~재방문)은 **양쪽 완전 동일**. 갈리는 건 **추천 행(노출·문턱·보상)** 뿐.

### 논의 필요 지점

1. 🟡 **노출 규칙** — 완료 화면 매번 노출 ❌ → 권고: **성취 정점 + 7일 1회 상한**
2. 🟡 **신규 친구 정의 / 어트리뷰션** — 완전 신규만? 휴면·재설치 처리? 딥링크 vs 코드 우선순위
3. 🟡 **보상 회수(claw-back)** — 친구가 환불/차지백하면 추천인 보상 회수하나
4. 🟡 **상한·약관** — 연 12개월 외 월/일 상한 + **자동결제·이벤트 약관 고지** (⚠️ 해외 교민 타겟 → 미국 등 자동갱신 고지법 대응 필요)
5. 🟡 **인트로 기간 N=3개월** 확정 여부
6. 🟡 **MVP 범위** — 풀자동 전에 **수동 초대코드 + 어드민 수동 보상지급**으로 소규모 검증할지 (아래)

## 기술 검토 필요 지점

> ⚠️ 플랫폼: **iOS / Android 둘 다**, 결제 플로우는 **이미 보유**.

1. **딥링크 어트리뷰션** — Branch.io / AppsFlyer (Firebase Dynamic Links 2025 종료). ⚠️ 해외 다국가 환경 대응 필요
2. **IAP 무료개월 지급** — iOS 프로모션 오퍼/오퍼코드 + Android 프로모션 코드, 또는 **RevenueCat 등 서버 entitlement로 양 OS 통합**
3. **어뷰징 탐지** — 결제수단/기기/IP dedup, 자기초대(다계정) 차단. ⚠️ 국가 간 결제수단 식별 정확도
4. **추천관계 트래킹 DB + 보상 상태머신** — 카운트 → (친구 첫 결제까지) 홀드 → 지급 / 회수
5. **어드민 기능** — 수동 검수, 보상 회수, 진행률·히스토리(마이페이지)

### (추가) 성공 지표 (KPI)

- **K-factor** (초대당 신규 유입)
- 초대 → **적격 전환율**, 적격 → **첫 결제 전환율**
- **레퍼럴 CAC vs 광고 CAC**
- 추천 경유 유저 **D30 리텐션** vs 일반 유입
